# Herdr 파일 뷰어

Files에서 문서를 선택하면 같은 작업 공간에서 내용을 읽을 수 있습니다.

## 문서 읽기

| 파일 | 조작 | 결과 |
| --- | --- | --- |
| Markdown | Source | 원문 보기 |
| Markdown | Preview | 서식 있는 문서 보기 |
| PDF | Ctrl + 휠 | 마우스 위치를 기준으로 확대·축소 |

## 나란히 보기

1. Files에서 비교할 파일을 선택합니다.
2. **Ctrl+Enter**를 눌러 오른쪽 분할 창에서 엽니다.

설치 상태는 압축을 푼 폴더에서 확인할 수 있습니다.

```powershell
.\Diagnose-Windows.cmd
```
